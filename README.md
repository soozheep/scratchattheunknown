# Scratch At the Unknown

**Sonic Remedy : Audiosensory Resonance**

By Soozhee · Produced by Caelverum Music

Live at: [scratchattheunknown.vercel.app](https://scratchattheunknown.vercel.app)

## Setup
1. Upload assets into the `assets/` folder (see structure below).
2. Deploy to Vercel (connect this repo).

### Required Assets (use exact filenames from Google Drive)

```
assets/
├── satu-cover.PNG                  # Cover art
├── 01_Scratch-At-the-Unknown.mp3   # Main track (rename the Drive file if needed)
├── lyrics/
│   ├── satu-01.png
│   ├── satu-02.png
│   ...
│   └── satu-14.png
└── cards/
    ├── satu-card-01.png
    ├── satu-card-02.png
    ├── satu-card-03.png
    └── satu-card-04.png
```

After uploading the files, the site is ready.
